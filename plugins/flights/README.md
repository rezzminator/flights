# flights

Claude Code plugin for the flights agents that build and land work — two foremen, a lander with its three reviewers, a speccer, /flights:spec and /flights:doctor — and a codebase map, a names-only tree of every entry at the repository's root and the first 6 entries of each folder under it, given to the main chat and the flights builder agents at their start, cached per commit.

The agents, each spawned as `flights:{name}`: `flights:foreman` (Opus) and `flights:foreman-sonnet` (Sonnet, the same manual) build one request each; `flights:lander` takes their worktree to merge-ready, spawning the review its kit `flights:lander-inventory` computes from `flights:hunter`, `flights:spec-walker` and `flights:sub-lander`; `flights:speccer` designs novel work through `/flights:spec`; `/flights:doctor` measures a flight. They hand git writes and lookups to Professor's agents (`gitter`, `tracer`, `pcm`, `documenter`) and `/flights:doctor` reads runs through Professor's `pfm`.

At each `SessionStart` of the main chat, and at the `SubagentStart` of the agent types `flights:foreman`, `flights:foreman-sonnet`, `flights:lander`, `flights:hunter` and `flights:sub-lander`, the session's git repository is mapped as a names-only tree: every entry at its root, folders first and then files, each by name, and under each root folder its first 6 entries, then `… N more`. The entries are the paths git lists — tracked files and untracked ones not ignored — that the work tree still holds; a folder's name ends in `/`, and a submodule shows as a folder. The map is cached per commit under `${XDG_CACHE_HOME:-$HOME/.cache}/flights/map/`. A map that cannot be built is said in one `Codebase map unavailable: {reason}` line; outside a git repository nothing is added. The hook answers within 4.5 seconds and has no settings.

Install with `claude plugin install flights@professor` after `claude plugin marketplace add rezzminator/flights`. Needs `python3` 3.9 or later and `git`. Limits: Claude Code only; the agents' hand-offs need Professor. Remove it with `claude plugin uninstall flights@professor`. Full documentation: <https://github.com/rezzminator/flights>
