# flights

Claude Code plugin for the flights agents that build and land work — two foremen, a lander with its three reviewers, a speccer, /flights:spec and /flights:doctor — and a codebase map read from each package's front door, one line per package folder, hottest first by how often the repository's files are read, given to the main chat and the flights builder agents at their start, cached per commit.

The agents, each spawned as `flights:{name}`: `flights:foreman` (Opus) and `flights:foreman-sonnet` (Sonnet, the same manual) build one request each; `flights:lander` takes their worktree to merge-ready, spawning the review its kit `flights:lander-inventory` computes from `flights:hunter`, `flights:spec-walker` and `flights:sub-lander`; `flights:speccer` designs novel work through `/flights:spec`; `/flights:doctor` measures a flight. They hand git writes and lookups to Professor's agents (`gitter`, `tracer`, `pcm`, `documenter`) and `/flights:doctor` reads runs through Professor's `pfm`.

At each `SessionStart` of the main chat, and at the `SubagentStart` of the agent types `flights:foreman`, `flights:foreman-sonnet`, `flights:lander`, `flights:hunter` and `flights:sub-lander`, the session's git repository is mapped: one line per Go package (`go list`), Python package (`__init__.py` docstring), `index.ts`/`index.js` or `lib.rs`/`mod.rs` folder, each with the first line of its front door's doc, or `(no front door doc)`. The map is cached per commit under `${XDG_CACHE_HOME:-$HOME/.cache}/flights/map/`, stays within 4000 characters with a footer counting the folders left out, and lists the hottest package folder first: each `Read` of any loop, recorded by an asynchronous `PostToolUse` hook, adds to its file's score, halved every 14 days, and a folder's heat sums its files' scores; never-read folders follow with the session's folder first. The scores are kept per repository under `${XDG_CACHE_HOME:-$HOME/.cache}/flights/heat/` and seeded once from this Claude Code config's transcripts of the last 30 days. When `go` is not on the hook's `PATH`, the background build asks the login shell for it. A map that cannot be built is said in one `Codebase map unavailable: {reason}` line; outside a git repository nothing is added. The hook answers within 4.5 seconds and has no settings.

Install with `claude plugin install flights@professor` after `claude plugin marketplace add rezzminator/flights`. Needs `python3` 3.9 or later and `git`, and `go` for a repository with Go modules. Limits: Claude Code only; the agents' hand-offs need Professor. Remove it with `claude plugin uninstall flights@professor`. Full documentation: <https://github.com/rezzminator/flights>
